# 情感陪伴智能体 - 记忆机制演示

## 📌 项目简介
这是一个基于大语言模型（DeepSeek）和SQLite结构化记忆模块的情感陪伴对话原型。本项目旨在验证外挂记忆机制对跨轮次情感一致性的影响。

## ✨ 核心功能
- **长期记忆**：将用户提到的关键情感事件存入SQLite数据库。
- **记忆检索**：在后续对话中，自动检索相关历史记忆并注入Prompt。
- **A/B对照**：侧边栏可切换“有记忆”和“无记忆”模式，直观对比效果。

## 🚀 如何体验
直接在网页端与智能体对话即可。建议测试流程：
1. 在B组（有记忆）模式下，告诉它一件有情绪的事（如“我下周要面试，好焦虑”）。
2. 聊点别的（如“今天天气不错”）。
3. 观察它是否能在后续对话中自然关联回之前的事。

## 🛠️ 技术
- 大模型：DeepSeek API
- 记忆存储：SQLite
- 前端框架：Streamlit
